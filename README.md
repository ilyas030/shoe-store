# 👟 ShoeStore — интернет-магазин обуви

Учебный проект на HTML, CSS и JavaScript.

**Автор:** Минибаев Ильяс

## Возможности

- Каталог обуви: кроссовки, ботинки, туфли, сандалии
- Фильтрация товаров по категориям
- Корзина с сохранением в localStorage
- Автоматический подсчёт суммы
- Адаптивная вёрстка

## Структура проекта

- index.html — разметка страницы
- style.css — оформление
- script.js — логика (корзина, фильтры)
- README.md — описание проекта (этот файл)
- test.txt — тестовый файл

## Запуск

1. Скачайте папку проекта
2. Откройте index.html в браузере
